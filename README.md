# Maruti Electricals Website

GitHub Pages-ready static website.

## Upload
Upload the files in this folder directly to the root of your GitHub repository.
Then open **Settings → Pages → Deploy from a branch → main → /(root)**.

## Edit business contact details
Open `app.js` and change the `BUSINESS` object at the top.

## Edit products / generic images
Open `app.js` and edit `PRODUCTS` and `IMAGES`.
The current images are generic Unsplash placeholders and can be replaced later with actual product photos.
